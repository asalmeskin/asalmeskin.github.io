This version uses a compact, minimal academic layout with smaller typography and reduced spacing.

## Website files

- `index.html`
- `styles.css`
- `script.js`
- `.nojekyll`

## Publish with GitHub Pages

For the address:

```text
https://asalmeskin.github.io
```

your GitHub username must be `asalmeskin`, and the repository name must be:

```text
asalmeskin.github.io
```

Upload the files to the repository root, then open:

**Settings → Pages → Deploy from a branch → main → / (root)**
